# S5.1 撤桥前置施工规格（executor 执行单）

> 目标：消除 API 模式下全部镜像文件读依赖（撤桥阻断项 A1/A2/A3/A6/A7/A12），清理施工孤儿（B1/B6）。

## 1. A12：marker 迁出镜像根（最高优先）

`data_root.rs`：
- `marker_path()` 默认路径改为 `~/.questlog-remote-mode.json`（固定位置，不再寄生于 mirror_root）；`QUESTLOG_REMOTE_CONFIG` env 覆盖保留。
- 文档注释同步（marker 位置契约）。

`scripts/questlog-bridge-mirror.sh`：marker 写入 `$HOME/.questlog-remote-mode.json`（tmp+mv 同前）；镜像根内旧 `REMOTE_ACTIVE` 不再写（不删旧文件）。

主模型部署时会手动写新位置 marker（含 api_base）——你不用管运行态。

## 2. A1：get_projects 计数服务端化

`api_server.rs` 新路由 `GET /api/projects-full`：`map_store(crate::commands::get_projects_impl(&crate::discovery::discover_projects()))`（返回与 GUI 命令完全同形 payload）。
`commands.rs` get_projects 远程分支：改为 `crate::remote_client::get_into("/api/projects-full")` 直接返回（删除现有的"裸列表+本地计数组装"路径）。原裸 `/api/projects` 路由保留不动（smoke/tray 别动）。

## 3. A2/A3：executions 视图字段服务端化

`api_server.rs`：
- `/api/executions` 路由改为：`list_executions()` 后经 `fill_execution_view_fields`（execution_store 内既有函数，m5p 本地权威数据填充 retries_remaining/display_no），返回已填充列表。
- 新路由 `GET /api/current-execution`：`map_store(crate::commands::get_current_execution())`（纯函数直调，标题查找在服务端对权威路径生效）。

`commands.rs`：
- get_executions 远程分支：直接 `get_into("/api/executions")`，**删除本地 fill 调用**（镜像 join 移除）。
- get_current_execution 远程分支：`get_into("/api/current-execution")`（替代现有"API 列表+本地 payload 组装"路径，相关本地辅助调用若因此零消费则一并清理——`freshest_inflight`/`current_execution_payload` 若仅该分支用则删）。

## 4. A6/A7：arb 配置 API 化

`api_server.rs` 新路由 `GET /api/arb-config`：返回 `crate::discovery::get_arb_board_config()` 的序列化（函数若为私有/内部，在 discovery.rs 提 pub 或按现有导出适配；返回形状含 enabled/board_path）。
`commands.rs` get_arb_board 远程分支：先 `get_into("/api/arb-config")` 拿配置（含 M4 本地 board_path 字段），然后**沿用现有本地 board.json 读取逻辑**（board 文件本体留 M4，设计内）。
`watcher.rs` arb 腿：`api_mode` 时配置来源改 API（`enabled_arb_board_path` 的 API 等价——可抽一个 `fn arb_board_path() -> Option<String>`：api 模式走 remote_client，否则走 discovery），watch 本地父目录逻辑不变。
