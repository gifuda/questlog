## 二、acceptance ⑬ 专项场景证据（测试名 → 断言内容）

### 1. 路径越界硬门禁（S3）
- `scope_violation_on_unauthorized_create` / `scope_violation_on_unauthorized_modify`：新文件无 create 权、已有文件无 modify 权（create 匹配已有文件不算数）→ 熔断
- `create_rights_allow_new_files_v1_fallback_and_v2_split`：v1 回退（无 create_paths → allowed 兼新建）与 v2 分离并存
- `scope_violation_on_forbidden` / `scope_always_rejects_control_plane_files`：forbidden 与控制平面优先
- MCP 端：`rejects repository-wide creation patterns`（`**`/`**/` 前缀 create 模式拒绝）

### 2. 软阈值继续 + 极端数量熔断（S3/S4）
- `scope_size_verdict_tiers`：四态边界（=expected/=warn/=max；None 级不触发——**仅 max 时与旧行为等价**）
- `path_violations_reported_before_count_breaker`：**先报具体路径后判数量**（越界+超量并存时报路径）
- `path_violations_reported...` 第二段：全路径合规但超 max → TooManyFiles 熔断
- OverWarn 不阻断：runner 接线段只写 `manifest.scope_size_warning` + candidate trailer，无 return（代码路径审查 + `enforces expected ≤ warn ≤ max ordering`）

### 3. 熔断前证据保全（S1）
- `scene_snapshot_captures_full_worktree_state`：tracked staged+unstaged diff + untracked 拷贝 + post-base commits + 完整分类
- `scene_snapshot_none_for_clean_tree`：空场景=None
- `integrity_hash_covers_scene_dir`：**篡改 scene 文件必须验签失败**
- `seal_bundle_captures_scene_and_flags_execution`：集成——manifest.scene_ref + execution.scene_preserved 写回
- 保留现场闸：`scene capture failed/partial → keep worktree`（poll 兜底，`timeout_terminates_executor_process_group` 回归内覆盖清理路径）

### 4. 批准后复用续跑（S2）
- `scene_recovery_round_trips_into_fresh_worktree`：同 base 恢复逐字节一致
- `scene_recovery_fails_on_drifted_base`：**base 漂移大声失败降级全新执行**
- `find_recoverable_scene_filters_and_selects_newest`：同 package + scope_violation + **同 base** + **scene_preserved=true** 才可选；数量熔断（scope_count_violation）不入选
