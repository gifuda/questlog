# 桌面清单贴 功能需求设定 v1 —— 晨报首屏与布局重构

2026-10-08 · grill-me 访谈收口 · 状态：待用户过目修订

## 脊柱（D1）

布局优先服务**早晨开机总览**：打开即见——昨晚机器干了什么、有什么等我拍板、今天焦点在哪。

## 用户时刻框架

| 时刻 | 看什么 | 决断什么 | 位置 |
|---|---|---|---|
| 早晨开机 | 晨报（跨源）+ 决断计数 + 各项目焦点 | 读为主 | **晨报 tab（首屏默认）** |
| 随手记/处理待办 | 三列看板 + 待确认区 | 卡片操作、夜间授权 | 待办 tab |
| 方案推进 | 总表 + 焦点信号 + Runner 控制 | 方案管理、执行监控 | 方案 tab |
| 套利处置 | 晨报深度区 + 决策处置 + 假设/线索 | 批准/驳回 | 套利 tab |

## 决策明细

- **D2 晨报跨源合一**：首屏晨报段聚合 GROS 晨报（brief/机会橱窗）+ QuestLog 夜间 digest + 决断计数；套利页保留决策处置与深度列表。
- **D3 待决断=计数+跳转**：首屏只显示各类待决断的计数徽章（DR / 待确认 / 套利决策），点击跳转到各自页面处置。不做统一队列。
- **D4 tab 结构**：晨报吞并现有"总览"tab（跨项目焦点信号并入晨报下半区）。最终四 tab：**晨报（默认）| 待办 | 方案 | 套利**。
- **D5 托盘迷你版**：托盘弹窗改为晨报速览（决断总计数 + 晨报标题 + 各项目在办计数），点击直达主窗对应位置。

## 约束（覆盖检查固化）

1. 首屏**纯只读**——任何处置动作必须发生在其所属页面（既有闸门不动：review gate、决策白名单、两段确认）。
2. 全部**读时聚合**，零新写路径、零新数据文件。
3. 各数据源独立降级：GROS 缺失→晨报段置灰；无夜间活动→"昨夜无事"；DR 为空→不渲染该徽章。
4. 晨报必须带**时效标记**（brief_date / digest 日期），过夜数据要可辨识。
5. 字号/色板沿用既有 token 体系与 11/13px 下限，不产生新特例。

## 非目标

- 不动三列看板、方案总表、套利列表的内部布局
- 不做统一决断队列（D3 已排除）
- 不改任何执行链路语义

## 后续

用户过目修订 → 布局方案（线框）→ 施工。施工时"总览 tab"的 Overview.tsx 组件内容并入晨报页，不丢弃。
