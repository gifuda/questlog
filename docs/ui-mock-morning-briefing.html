托盘弹窗 = 晨报迷你版（D5）
点击行 → 主窗对应位置

D1 / 首屏默认

app 打开落在此页。三秒回答：昨晚发生了什么、我要拍几件板、今天先看哪个项目。

D2 / 晨报卡

GROS 晨报与 QuestLog 夜间 digest 合一展示，来源标注在卡片右上。各数据源独立降级：缺一置灰该段，不拖垮整卡。

D3 / 决断卡

只显示计数与摘要，「处置 →」跳回各自页面——review gate、决策白名单、两段确认全部留在原地，首屏零写权限。

D4 / 焦点区

原「总览」tab 内容并入此区：每项目一行（计数 + 单焦点信号），点击行直达该项目方案页。

健康灯带

全局共享，晨报页同样可见——窗口漏跑/回执滞留这类信号不应该只在方案页才能看到。

时效标记

晨报日期、digest 日期固定显示（mono 字体），过夜数据一眼可辨。
